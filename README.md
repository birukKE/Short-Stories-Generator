# Short-Stories-Generator


This assignment implements a Transformer-based language model that takes BPE token IDs and produces logits for the next token at every position. The model adds learned token and positional embeddings, passes them through causal self-attention and Transformer blocks, and finally uses a linear layer to predict one of 5,000 possible tokens. During training, the default model improved significantly, with dev loss decreasing from 2.1182 at 10,000 iterations to 1.5345 at 1,000,000 iterations, while generated stories became more fluent, coherent, and appropriately structured. In comparison, the smaller 1-block/1-head model achieved a higher dev loss of about 1.9798 and produced more repetitive and less coherent stories.
